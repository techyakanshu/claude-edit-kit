# 🎬 Claude Editing Kit

Ek double-click aur Claude se video editing ka poora setup ready. Na folder banana, na koi command likhni.

---

## 🍎 Mac (MacBook / iMac)

**Download:** [Claude-Editing-Mac.zip](https://github.com/techyakanshu/claude-edit-kit/raw/main/Claude-Editing-Mac.zip)

1. Download hui zip par double-click karo, folder khul jayega.
2. **Claude Editing Setup** file par double-click karo.
3. Mac bolega *"Apple could not verify…"* → **Done** dabao.
4. **System Settings → Privacy & Security** kholo → neeche scroll karo → **Open Anyway** → **Open**.
   (Ye sirf pehli baar. Purane macOS par: file par right-click → **Open** → **Open**.)
5. Terminal khulega, 2–5 minute mein sab install ho jayega. Koi password nahi maangega.
6. Desktop par **Claude Editing** folder ban jayega.

---

## 🪟 Windows (10 / 11)

**Download:** [Claude-Editing-Windows.zip](https://github.com/techyakanshu/claude-edit-kit/raw/main/Claude-Editing-Windows.zip)

1. Zip par right-click → **Extract All** → **Extract**.
2. **Claude Editing Setup** (.bat) file par double-click karo.
3. Blue box aaye *"Windows protected your PC"* → **More info** → **Run anyway**.
4. Install ke beech *"Do you want to allow…"* popup aaye to **Yes** dabao.
5. 3–5 minute mein sab install ho jayega, window mein "Setup ho gaya" aayega.
6. Desktop par **Claude Editing** folder ban jayega.

---

## ✂️ Uske baad (dono ke liye same)

1. `1-Reference` mein wo reel daalo jiske jaisa edit chahiye.
2. `2-Meri-Video` mein apni video daalo.
3. Claude app kholo (Windows par pehle band karke dobara kholo) → **Code** tab → **Claude Editing** folder chuno.
4. Likho: **"meri video ko reference jaisa edit kar do"**
5. Edit hui video `3-Final` mein aa jayegi.

## Kya install hota hai
ffmpeg, yt-dlp, Node.js aur uv (captions ke liye Whisper). Mac par sab `~/.claude-edit` mein jaata hai (Homebrew ya password nahi chahiye). Windows par winget se install hota hai.
